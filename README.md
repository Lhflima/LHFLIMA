# Bella Beleza — Loja de produtos de beleza

Site estático e genérico para revenda de produtos **Natura**, **Mary Kay** e **O Boticário**.

## Recursos
- Página inicial com banner, benefícios, marcas, categorias, promoções, depoimentos e newsletter
- Catálogo com filtro por marca e categoria, busca e ordenação por preço
- Sacola de compras (salva no navegador) com finalização do pedido pelo WhatsApp
- Layout responsivo (celular, tablet e desktop)

## Como usar
Abra o `index.html` no navegador — não precisa de instalação.

Para personalizar:
- **WhatsApp**: altere `WHATSAPP_NUMBER` no início de `script.js`
- **Produtos**: edite a lista `PRODUCTS` em `script.js` (nome, marca, categoria, preço e URL da imagem)
- **Contato/rodapé**: edite o final do `index.html`

## Observações
Imagens ilustrativas do [Unsplash](https://unsplash.com). Nomes de produtos e preços são exemplos.
Natura, Mary Kay e O Boticário são marcas registradas de seus respectivos proprietários; este é um site de revenda independente.
